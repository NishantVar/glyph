# Bug Audit — Glyph Repository

This index covers the full results of a bug audit of the Glyph repository (date: unknown-date). A total of **90 confirmed bugs** were identified across the compiler, LSP, formatter, IR emitter, tree-sitter grammar, scripts, and documentation. By severity: **1 critical**, **10 high**, **36 medium**, **43 low**. All 90 findings were adversarially verified (see Methodology below). Five candidate findings were reviewed and rejected as non-bugs; see [REJECTED.md](REJECTED.md) for those. No unverified findings remain.

## Methodology

The audit deployed **37 parallel region and cross-cutting finder agents**, each targeting a distinct slice of the codebase (compiler crates, LSP, formatter, IR emitter, tree-sitter grammar, scripts, documentation, tests, etc.) in parallel. Every candidate finding was then subjected to an **adversarial verification loop**: an independent refuter agent attempted to disprove the finding, a reproducer agent attempted to confirm it, and a tiebreaker resolved any split verdict. Live `cargo build`, `cargo test`, and `cargo clippy` runs were used throughout to validate real-world reproducibility. All candidates were **LLM-deduplicated** before verification to collapse near-duplicates into single authoritative findings. A final **completeness-critic gap round** re-examined areas with low finding density to check for missed issues before the audit was closed.
